# Steel Surface Defect Detection — Web Demo

เว็บสาธิตสำหรับตรวจจับตำหนิพื้นผิวเหล็กด้วย YOLO11s และ YOLOv8s ที่ฝึกบนชุดข้อมูล NEU-DET
ผู้ใช้อัปโหลดภาพ แล้วระบบแสดงกรอบล้อมรอบตำหนิ ชนิด ค่าความเชื่อมั่น เวลาประมวลผล และรุ่นของโมเดลที่ใช้

เว็บนี้เป็นต้นแบบจากงานวิจัยเรื่องผลของการเสริมข้อมูล (data augmentation) ต่อการตรวจจับตำหนิผิวเหล็ก
ไม่ใช่ระบบตรวจสอบคุณภาพสำหรับสายการผลิตจริง

## ความสามารถ

- อัปโหลดหลายภาพ ลากมาวาง วางจากคลิปบอร์ด (Ctrl+V) หรือถ่ายภาพจากกล้อง (JPG, PNG, BMP ไม่เกิน 10 MB)
- เลือกตระกูลโมเดล YOLO11s / YOLOv8s และเงื่อนไขการเสริมข้อมูล (B0, B_default, B1–B7) รวม 18 รุ่น
- threshold ของแต่ละรุ่นถูกตรึงไว้จากชุด Validation ปรับเองไม่ได้
- ภาพสีแปลงเป็นระดับเทา ภาพขนาดต่างจาก 200×200 ย่อทั้งภาพ หรือตัดเป็นช่อง 200×200 แล้วรวมผล (โหมดทดลอง)
- เทียบผลของทุกเงื่อนไขบนภาพเดียวกัน
- แผนที่ความสนใจแบบ Eigen-CAM (ส่วนเสริม)
- เทียบกับกรอบเฉลยเมื่อเป็นภาพชุด Validation ของ NEU-DET
- บันทึกภาพ PNG และผลตรวจเป็น CSV (รายภาพหรือทุกภาพ)
- โหมดมืด/สว่าง รองรับหน้าจอโทรศัพท์ (กว้าง 375 px ขึ้นไป)
- ไม่บันทึกภาพที่อัปโหลดลงดิสก์

## ความต้องการ

- Python 3.12 ขึ้นไป
- ใช้ CPU อย่างเดียวได้ (ประมาณ 130 ms ต่อภาพบน CPU ของโน้ตบุ๊ก; ประมาณ 15 ms บน NVIDIA RTX 3050 Laptop)
- RAM ไม่น้อยกว่า 4 GB และพื้นที่ว่างประมาณ 3 GB
- `ultralytics==8.4.170` (ต้องตรงกับรุ่นที่ใช้ฝึก แอปจะไม่เริ่มทำงานถ้ารุ่นไม่ตรง)

## การติดตั้ง

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r web/requirements.txt
```

หากมี GPU ของ NVIDIA ให้ติดตั้ง PyTorch รุ่นที่รองรับ CUDA ก่อน เช่น

```bash
pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu126
```

### ไฟล์โมเดล

ไฟล์โมเดลของ 2 รุ่นหลักอยู่ใน [Releases](https://github.com/Ginny421/steel-defect-web-demo/releases) ของ repo นี้
(ประมาณ 19 MB ต่อรุ่น) ดาวน์โหลดและตรวจ sha256 ด้วยคำสั่ง

```bash
python download_weights.py
```

สคริปต์จะวางไฟล์ที่ `web/weights/B5_s52/best.pt` (ปุ่ม YOLO11) และ `web/weights/V8_B5_s62/best.pt` (ปุ่ม YOLOv8)
และลบไฟล์ทิ้งหากรหัส sha256 ไม่ตรงกับ `research/registry.csv`
อีก 16 รุ่นที่ใช้ในตารางเทียบเงื่อนไขไม่รวมอยู่ใน release รุ่นที่ไม่มีไฟล์จะไม่ปรากฏให้เลือก
หากมีไฟล์ของรุ่นอื่น ให้วางที่ `web/weights/<run_id>/best.pt`

## การใช้งาน

```bash
python web/app.py
```

เปิดเบราว์เซอร์ที่ <http://127.0.0.1:8000>

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `HOST` | `127.0.0.1` | ตั้งเป็น `0.0.0.0` เพื่อให้เครื่องอื่นในเครือข่ายเข้าถึง (ใช้เฉพาะเครือข่ายที่เชื่อถือได้) |
| `PORT` | `8000` | พอร์ตของเซิร์ฟเวอร์ |
| `WEB_DEMO_DEV` | ไม่ตั้ง | `1` = โหมดพัฒนา ข้ามการตรวจ sha256 และรุ่นของ ultralytics |

ค่าตั้งอยู่ใน `web/config.yaml`

```yaml
run_id: B5_s52
weights: web/weights/B5_s52/best.pt
demo_runs:
  YOLO11s: B5_s52
  YOLOv8s: V8_B5_s62
device: cpu          # มี GPU ให้ใส่ 0
max_upload_mb: 10
```

## โครงสร้าง

```
download_weights.py   ดาวน์โหลดไฟล์โมเดลจาก Release
web/
  app.py            เซิร์ฟเวอร์ FastAPI
  config.yaml       ค่าตั้งของเว็บ
  static/index.html หน้าเว็บ (หน้าเดียว)
  tests/            ชุดทดสอบ (pytest)
  weights/          ไฟล์โมเดล (ไม่อยู่ใน repo)
research/
  registry.csv                  รายชื่อรุ่น นโยบายการฝึก seed และ sha256 ของ best.pt
  reports/thresholds_val.json   threshold ที่ตรึงจากชุด Validation
  reports/freeze/               sha256 ของรุ่นที่ตรึงแล้ว
  eval/                         ตัวแปลงผลทำนายและตัวประเมิน
  stats/eigen_cam.py            แผนที่ความสนใจ
  data/                         ชื่อคลาส และ manifest ของข้อมูลสำหรับกรอบเฉลย
```

## ข้อจำกัด

- โมเดลฝึกด้วย NEU-DET เพียงชุดเดียว ตอบได้เฉพาะตำหนิ 6 ชนิด (pitted surface, inclusion, patches, rolled-in scale, crazing, scratches)
- ภาพที่ให้ผลใกล้เคียงงานวิจัยที่สุดคือภาพระดับเทาขนาดประมาณ 200×200 พิกเซลแบบเดียวกับ NEU-DET
- ข้อความ "ไม่พบตำหนิ" ไม่ได้ยืนยันว่าภาพไม่มีตำหนิ โมเดลหลักตรวจไม่พบตำหนิประมาณ 41–48% ของตำแหน่งบนชุด Test
- ผลบนภาพที่ผ่านการแปลง (ย่อ/ตัดช่อง) ไม่ได้ผ่านการประเมินในงานวิจัย ใช้ดูการทำงานของระบบเท่านั้น
- ผลจากภาพเดียวไม่สามารถใช้สรุปว่าเงื่อนไขใดดีกว่า
